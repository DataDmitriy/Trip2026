# Trip Helper · Семейная поездка 2026

Mobile-first PWA для семейной поездки **Будапешт → Париж/Disneyland → Биллунн (Леголенд) → Амстердам** (16 дней, 6–22 мая 2026).

Заточено под Pixel 10 / Pixel 8 Pro: ставится «как приложение» с иконки на главном экране, тёплая кремовая палитра, Material 3.

## Стек

- **Next.js 14 (App Router)** — один проект и для UI, и для serverless API
- **Mapbox GL JS** — интерактивные карты Европы и каждого города с пинами мест
- **Anthropic Claude (`claude-haiku-4-5`)** — AI-помощник, знающий весь маршрут, режим сна Лёвы и багаж
- **PWA**: manifest + service worker (кеш карт + app-shell)
- **lucide-react** для иконок, design tokens из дизайн-хендоффа

## Локальный запуск

```bash
npm install
cp .env.example .env.local
# ↓ заполните токены ↓
npm run dev
# → http://localhost:3000
```

### Токены

| Переменная | Где взять | Зачем |
|---|---|---|
| `NEXT_PUBLIC_MAPBOX_TOKEN` | https://account.mapbox.com/access-tokens/ — создайте public token | Карты Европы и городов |
| `ANTHROPIC_API_KEY` | https://console.anthropic.com/settings/keys | AI-помощник |

Без `NEXT_PUBLIC_MAPBOX_TOKEN` приложение работает, но карты заменяются плейсхолдером. Без `ANTHROPIC_API_KEY` чат вернёт ошибку с подсказкой.

## Деплой на Vercel (бесплатно)

1. Подключите репозиторий `MyDataHubPro/landing` к Vercel.
2. В Project Settings → Environment Variables добавьте `NEXT_PUBLIC_MAPBOX_TOKEN` и `ANTHROPIC_API_KEY`.
3. Vercel сам поднимет API-роут `/api/chat` как serverless-функцию — отдельный сервер не нужен.

## Установка на Pixel 10 / 8 Pro

1. Откройте задеплоенный URL в Chrome на Pixel.
2. Меню `⋮` → **«Установить приложение»** (или Chrome сам предложит баннер при первом визите).
3. Иконка появится на главном экране, открывается в полноэкранном режиме без браузерного UI.

## Что внутри

- **Карта Европы** с маршрутом и кликабельными пинами 1–4
- **Город** — карта с домом и местами, фильтры (главное / для детей / наука / еда), карточки мест
- **Карточка места** — фразы «что сказать детям», лайфхак для семьи, CTA «спросить» / «как добраться»
- **Дневник 16 дней** — таймлайн с особым стилем для сна Лёвы 13:00–15:00
- **AI помощник** — знает все 22 места, перелёты, режим, бюджет; принимает контекст экрана
- **Перелёты** — 4 рейса с предупреждением о конфликте AF1295 со сном
- **Багаж** — чек-лист (хранится в localStorage), **Бюджет**, **Детские фильтры**

## Известные ограничения

- Координаты мест проставлены для центра города + ключевых точек, но не все места геокодированы 100% точно — поправьте в `src/lib/trip.ts` по необходимости.
- Маршруты «как добраться» сейчас эвристические; интеграция с Mapbox Directions / Google Directions — следующий шаг.
- Service worker кеширует карты, но не данные конкретных Mapbox-стилей в офлайне для всей Европы — для полного оффлайна нужен MBTiles + maplibre-gl. На семейной поездке хватит роуминга.
